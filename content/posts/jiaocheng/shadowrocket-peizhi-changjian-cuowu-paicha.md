## 二、分步图文教程与详细配置流程

按照以下标准化步骤操作，小白用户可在 3 分钟内完成全套设置：

### 步骤 1：下载并安装正版客户端
请务必通过官方 GitHub 或本站导航下载最新版软件，切勿使用第三方修改版或破解版，防止订阅链接与个人数据泄露。

### 步骤 2：获取并复制机场订阅链接
登录您的机场后台（如灵动云或暮光网络），找到“一键订阅”按钮，选择对应客户端类型的订阅链接并点击复制。

### 步骤 3：导入订阅并配置分流规则
1. 打开客户端，进入“订阅/配置 (Profiles)”界面。
2. 将复制的链接粘贴至 URL 输入框，点击“导入 (Download / Import)”。
3. 在设置中将运行模式切换为 `Rule`（规则分流），并开启 `TUN Mode`（虚拟网卡模式）。
4. 在节点列表 (Proxy) 中勾选延迟最低的节点（如“香港 IPLC 01”）。

### 步骤 4：连通性测试与验证
打开浏览器访问 Google 或 YouTube，若能瞬间加载且国内网站访问正常，即代表配置成功。


## 三、常见配置报错与排查指南

| 错误现象 | 可能原因 | 解决办法 |
| :--- | :--- | :--- |
| **节点延迟显示 Timeout** | 订阅未更新或本地 DNS 污染 | 点击更新订阅，重新启动客户端或重置 DNS |
| **能发消息但网页打不开** | 系统代理未正确接管 | 检查是否开启 TUN 模式或清除浏览器代理插件 |
| **ChatGPT 提示拒绝访问** | 节点 IP 触发风控 | 切换至灵动云的原生 IP 专线节点 |
| **国内网页打不开** | 分流规则设置错误 | 将模式从 Global（全局）切回 Rule（规则） |
